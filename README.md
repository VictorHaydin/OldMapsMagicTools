# OldMaps.com.ua Magic Tools

Розширення для Chrome (Manifest V3) з двома незалежними наборами функцій для
двох різних сайтів зі старими картами:

- **[oldmaps.com.ua](https://oldmaps.com.ua)** — додаткова панель налаштувань
  для порівняння історичних карт.
- **[uma.lvivcenter.org](https://uma.lvivcenter.org)** — кнопка для завантаження
  зображення карти у максимальній роздільній здатності.

## oldmaps.com.ua: розширені налаштування перегляду карт

Розширення додає кнопку у вигляді чарівної палички поруч із власними кнопками сайту
"інформація"/"додому" (у правому верхньому куті перегляду карт). Клік по ній відкриває
панель налаштувань:

- **Вигляд мапи** — перемикає між двома режимами перегляду:
  - **Одна біля одної** (за замовчуванням) — звичайний вигляд сайту, карти поруч.
  - **На ввесь екран** — накладає обидві карти одна на одну на всю область
    перегляду, ліва карта відображається поверх правої. Карти залишаються ідеально
    вирівняними, оскільки вони синхронізуються власним кодом сайту
    (`leftmap.sync(rightmap)`); розширення лише змінює розмір обох контейнерів до
    однакового повноекранного прямокутника і каже Leaflet перемалюватися
    (`invalidateSize()`).

  Цей режим недоступний, поки на сайті активний його власний режим однієї карти
  (кнопка з іконкою вікна поруч із кнопкою "додому") — і навпаки, ця кнопка сайту
  вимикається, поки активний режим "На ввесь екран", щоб обидва режими ніколи не
  були активними одночасно.

- **Прозорість** — з'являється лише в режимі "На ввесь екран". Повзунок від 0 до
  100%, що керує прозорістю тайлів верхньої (лівої) карти, аби можна було
  "приглушити" її та побачити карту під нею, порівнюючи обидва шари в тому самому
  місці.

У режимі "На ввесь екран" дві кнопки вибору шару та дві панелі з інформацією про
джерело карти (зазвичай по одній на кожну карту) переміщуються так, щоб обидві були
видимі й розташовані одна над одною — елемент керування верхньої карти над елементом
керування нижньої — замість того, щоб один ховався за іншим.

> Раніше розширення мало власний перемикач "Показати центр" для червоного хрестика
> в центрі карти. Його прибрано, оскільки сайт згодом додав власну кнопку
> (з іконкою прицілу) з тією ж функцією — тримати дублікат більше не було сенсу.

## uma.lvivcenter.org: завантаження карти у максимальній роздільній здатності

На сторінках карт (наприклад,
[uma.lvivcenter.org/uk/maps/34441](https://uma.lvivcenter.org/uk/maps/34441)),
після кліку на зображення карти відкривається повноекранний переглядач. Під його
кнопкою закриття (у правому верхньому куті) з'являється кнопка завантаження. Клік
по ній:

1. Визначає повний розмір зображення та сітку тайлів найвищого рівня масштабування
   безпосередньо з активного екземпляра переглядача OpenSeadragon сайту (формат
   тайлів Zoomify).
2. Завантажує всі тайли цього рівня (кілька паралельних запитів із повторними
   спробами при збоях), показуючи прогрес прямо на кнопці.
3. Склеює їх у єдине зображення на `<canvas>` у оригінальному розмірі.
4. Експортує результат як JPEG і одразу зберігає його на диск через завантаження
   браузера.

## Встановлення (розпакований додаток)

1. Відкрийте `chrome://extensions` у Chrome.
2. Увімкніть **Режим розробника** (перемикач у правому верхньому куті).
3. Натисніть **Завантажити розпакований додаток** і виберіть цю папку.
4. Відкрийте будь-яку сторінку перегляду карт на oldmaps.com.ua (наприклад,
   `https://oldmaps.com.ua/lviv/?leftmap=200866&rightmap=google`) або сторінку
   карти на uma.lvivcenter.org (наприклад,
   `https://uma.lvivcenter.org/uk/maps/34441`) і відкрийте перегляд карти кліком
   по зображенню.

## Файли

- `manifest.json` — маніфест розширення (Manifest V3) з двома незалежними
  content script — по одному на кожен сайт.
- `content.js` / `content.css` — панель налаштувань і логіка для oldmaps.com.ua.
- `uma-content.js` / `uma-content.css` — кнопка завантаження та логіка
  склеювання тайлів для uma.lvivcenter.org.

## Технічні примітки

### oldmaps.com.ua

- Content script виконується в **основному ("MAIN") контексті** сторінки
  (`"world": "MAIN"` у `manifest.json`), а не в ізольованому контексті Chrome за
  замовчуванням. Це потрібно, бо логіці необхідний прямий доступ до власних
  глобальних об'єктів карт Leaflet сторінки (`window.leftmap`, `window.rightmap`,
  `window.layersleft`, `window.layersright`) — вони недоступні з ізольованого
  content script.
- `#leftmap` і `#rightmap` кожен створює власний CSS stacking context, тож коли обидва
  змінюють розмір до однакового повноекранного прямокутника в режимі накладання,
  елемент керування всередині `#rightmap` ніколи не зможе відобразитися поверх
  непрозорих тайлів `#leftmap`, незалежно від його `z-index`. Тому кнопки вибору шару
  та панелі атрибуції від'єднуються від свого початкового контейнера карти й
  переносяться в `document.body`, поки активний режим накладання (і повертаються назад
  при перемиканні на "Одна біля одної"), щоб їх можна було позиціонувати й
  розташовувати незалежно.
- Сайт застосовує частину власних стилів до елементів керування через селектори,
  прив'язані до предка (наприклад, `.leaflet-container .leaflet-control-attribution`),
  та через успадкування CSS (шрифт атрибуції походить від скороченого запису `font`
  у `.leaflet-container`). Коли елемент від'єднується від свого контейнера карти, ці
  правила перестають діяти, тож розширення повторно оголошує еквівалентні стилі
  напряму.
- `.leaflet-container` (тобто `#leftmap`) має власний непрозорий
  `background: #ddd`, окремий від панелі тайлів. Повзунок прозорості приглушує лише
  панель тайлів (`.leaflet-map-pane`), тож фон самого `#leftmap` теж примусово робиться
  прозорим у режимі накладання — інакше він залишається непрозорим позаду приглушених
  тайлів і блокує показ `#rightmap`.
- Розширення стежить за атрибутом `class` на `<body>` через `MutationObserver`,
  щоб коректно вмикати/вимикати обидва режими незалежно від того, яку саме кнопку
  (сайту чи розширення) натиснув користувач, і автоматично повертається в режим
  "Одна біля одної", якщо сайт перемкнувся в режим однієї карти, поки був активний
  режим "На ввесь екран".

### uma.lvivcenter.org

- Сайт використовує OpenSeadragon 2.4.2 із класичним форматом тайлів Zoomify
  (`TileGroup{N}/{рівень}-{колонка}-{рядок}.jpg`). Замість того, щоб окремо
  відтворювати алгоритм нумерації тайлів Zoomify, content script підміняє
  глобальну функцію-конструктор `window.OpenSeadragon`, щоб перехопити
  екземпляр переглядача, який створює сам сайт, а потім при кліку на кнопку
  завантаження читає його справжні `source.maxLevel` і `source.gridSize` та
  викликає його ж метод `source.getTileUrl(рівень, колонка, рядок)`. Це працює
  для будь-якої карти на сайті, а не лише для однієї конкретної, і не залежить
  від змін у реалізації тайлів на боці сайту.
- Як і для oldmaps.com.ua, і сам content script, і монкі-патч `OpenSeadragon`
  мають виконуватися в **основному ("MAIN") контексті** сторінки — глобальний
  об'єкт `OpenSeadragon`, який створює сторінка, недоступний з ізольованого
  content script.
- Кнопка завантаження додається як дочірній елемент `#zoomify-container` — того
  самого контейнера, що й власна кнопка закриття сайту (`.zoomify-close`), тож
  вона автоматично з'являється і зникає разом із переглядачем карти без
  додаткової логіки видимості.
- Тайли завантажуються з обмеженою паралельністю (6 одночасних запитів) із
  повторними спробами при мережевих збоях, а прогрес відображається прямо на
  кнопці (заголовок-підказка та тонка смужка знизу).
